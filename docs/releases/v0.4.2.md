ClipForge 0.4.2 adds workshop cleanup and clearer controls for freeing disk space in the localhost Studio.

## Changes

- Delete completed, failed or interrupted items from workshop history.
- Optionally delete the associated imported source video from this computer at the same time. The dialog shows its size before confirmation.
- Saved-link deletion also offers source-file cleanup, selected initially when a managed source is available.
- Deleted source videos disappear from the visible library. Finished clips, captions and publication records are preserved.
- Running and queued tasks cannot be deleted. Source cleanup waits for active tasks to finish. Failed file cleanup leaves the history entry available to retry.
- ClipForge only deletes its managed imported source files. External files registered by path and separately downloaded copies remain untouched.

## Download and start

Download **clipforge-v0.4.2.zip**, extract it into a writable folder and run **Start-ClipForge.bat** on Windows or `bash ./start-clipforge.sh` on macOS/Linux. Python 3.11+ and FFmpeg/ffprobe are required; see README for optional local Whisper and Ollama setup. Existing users should keep their config, videos, models and data when updating.
