ClipForge 0.5.0 adds an **AI Story Generator** to the localhost video studio, with connected stickman animation and optional offline neural narrators.

## New story studio

- Turn an original story idea into a vertical animated MP4 with a local Ollama model, local narration, captions and procedural music/effects.
- Generate 30/60/90/120-second script targets, choose mystery/horror/suspense/science fiction, and export in 720p or 1080p. Actual running time follows the complete narration and may differ from the target.
- Connect walking, turning, reaching, opening, holding and reacting on a continuous motion timeline. Character positions, poses, carried props and camera motion continue between narration scenes, while changed environments blend smoothly.
- Keep reusable character designs, facial expressions and simple props such as keys, phones, books and flashlights. This is a minimalist 2D stickman renderer with supported actions and locations.
- Save and reopen projects, edit narration and motion cues, rewrite scripts, regenerate individual scenes, generate ideas, and queue batches of original stories.
- Cancel queued or running story generation while keeping saved projects and completed exports. Review and download finished videos through the existing clip controls.

## More local voices

- Preview installed narrators before making a full video.
- Browse a small catalog of Piper neural voices with language, download size, source, model card, license and attribution.
- Download chosen packs locally with measured progress, cancellation and pinned file integrity checks. Windows desktop voices and supported local eSpeak voices remain available.
- Control narration speed. Piper captions use measured short spoken phrases; Windows desktop voices can provide word highlights. No fabricated word timings are added.
- Your scripts and narration stay on your computer. Downloading a voice requires internet access; using an installed voice does not require a paid speech API.

## Studio improvements since 0.4.2

- Delete finished clips and their app-managed export files to free space.
- Stop supported active tasks and see measured stage progress and time estimates when sufficient measurements exist.
- Search, filter and sort clips. Existing source imports, clip editing and review-based social publishing remain available.

## Download and start

Download **clipforge-v0.5.0.zip**, extract the entire folder, and run **Start-ClipForge.bat** on Windows or `bash ./start-clipforge.sh` on macOS/Linux. Python 3.11+ and FFmpeg/ffprobe are required. This is a source distribution; Python, FFmpeg, Ollama, voice/model weights and your private configuration are not bundled.

For story rendering and optional neural voices, install these extras inside ClipForge's environment from the extracted project folder:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[stories,voices]"
```

On macOS/Linux use `.venv/bin/python -m pip install -e '.[stories,voices]'`. Configure your downloaded local model in Ollama, then open **AI Story Generator** and **Manage local voices**. See README and the included Story Generator guide for full setup.

**Updating:** stop ClipForge, update the public app files and install the extras above as needed, then restart. Keep your existing `config.json`, `data/`, `models/`, `secrets/` and videos; do not replace them with a new empty workspace. Earlier exports are kept when rendering new versions.
