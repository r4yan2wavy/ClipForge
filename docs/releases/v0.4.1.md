ClipForge is a browser video studio that runs on your computer. This release fixes a crash that prevented automatic speech captions from starting.

## Fixed

- AI setup now installs a PyAV version compatible with faster-whisper. Previously, a fresh installation could fail with `TypeError: open() got an unexpected keyword argument 'metadata_errors'`.
- Whisper readiness now tries the actual audio decoder, so an incompatible audio reader is detected in Settings.
- Unexpected AI errors identify the failed stage and error category. Local diagnostic records retain safe code locations without raw error messages, credentials or source URLs.

## What ClipForge includes

- Localhost Studio for importing, organizing, creating, reviewing and downloading clips.
- Public YouTube videos, Twitch recordings/clips, Kick recordings/clips and direct HTTPS video imports through local yt-dlp, plus local video files. Use sources you own or have permission to download and edit.
- Manual cuts and vertical crop, fit or blurred-background framing.
- Optional local Whisper transcription and timed captions, with Ollama selecting clip moments and proposing titles, descriptions and tags.
- Optional authorized publishing through the official YouTube, Instagram Reels and TikTok APIs, after review and confirmation.
- Delete an app-managed source video to free space while keeping finished clips and captions.

## Download and start

Download **clipforge-v0.4.1.zip**, extract it, install Python 3.11 or newer and FFmpeg/ffprobe, then run **Start-ClipForge.bat** on Windows or `bash ./start-clipforge.sh` on macOS/Linux. The launcher opens the local browser app and installs its Python requirements. See the included README for setup.

AI features require the separate local AI setup: the faster-whisper model and a running Ollama server with a downloaded local model. FFmpeg, JavaScript runtimes and model weights are not bundled. YouTube link imports require a supported local Node.js or Deno runtime. Source videos download onto the computer; processing does not require a paid cloud AI subscription. Link availability depends on provider changes and restrictions. No guaranteed viral results.

**Updating an existing AI setup:** stop ClipForge, update the project files, and run `.\.venv\Scripts\python.exe -m pip install -e ".[ai,links]"` from the project folder on Windows (`.venv/bin/python -m pip install -e '.[ai,links]'` on macOS/Linux). Restart ClipForge and check setup. Keep your existing config, data, source files and model folders; they do not need to be downloaded again.
